# Internship Login Assessment

A responsive login page developed for the code3x Internship Technical & Creative Assessment.

## Live Demo

https://internship-login-assessm-57d2c.web.app

## Features

- Responsive login page
- Email validation
- Password visibility toggle
- Google authentication using Firebase
- Displays the access token after successful login

## Technologies Used

- React
- TypeScript
- Vite
- Material UI
- Firebase
- React Router
